## How to redeem a code at Target (the exact steps)

Target puts the promo code box in a spot that's easy to miss: it's labeled **"Potential savings"** and sits above the Order Summary on Target.com, not below it like most retailers.

1. Add your items and go to checkout.
2. On Target.com, find the "Potential savings" section above the Order Summary and enter your code. In the Target app, tap "Add promo code" under that same section.
3. Select Apply or Redeem. The discount shows up in the Order Summary box.
